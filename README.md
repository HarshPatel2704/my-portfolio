Harsh Patel — Portfolio

A personal portfolio website built with "React + Vite", featuring a bold, minimal design with an animated hero, about section, project showcase, education timeline and contact section.

Live Preview
Run the project locally to preview it:

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

Tech Stack
- React 19
- Vite 8
- Oxlint
